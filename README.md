# Public_DeadRace

UE5 Dead Race Prototype

A simple Unreal Engine interview task.

Features:
- Chaos Vehicle
- Mixamo Character
- Pawn Sensing for basic NPC AI Behavior
- Health, Death and Scoring Systems
- Weapon, Projectile, Niagra
- Procedural Runtime Corridor Creation

Developed in Unreal Engine 5 using Blueprints.

Future improvements:
- Better Vehicle Handling
- Vehicle Drift
